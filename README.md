# Logwatch

CLI tool for the terminal. Zero dependencies.

```bash
curl -L https://raw.githubusercontent.com/neuralmint/logwatch/main/logwatch -o /usr/local/bin/logwatch
chmod +x /usr/local/bin/logwatch
```

Run `logwatch help` for usage.
